# PolyMind AI - Multi-LLM Orchestrator & Consensus Engine 🧠⚡

> **PolyMind AI** is an advanced AI Orchestrator that queries **ChatGPT (OpenAI)**, **Claude (Anthropic)**, **Gemini (Google)**, and **Ollama (Local LLM)** in parallel, compares their outputs side-by-side, and uses an automated consensus engine to synthesize the optimal unified response.

---

## 🌟 Key Features

- ⚡ **Parallel Multi-Model Execution**: Dispatch a single prompt simultaneously to ChatGPT (GPT-4o), Claude 3.5 Sonnet, Gemini 1.5 Pro, and local Ollama instances.
- 🎯 **Automated AI Consensus Engine**: Synthesizes common agreements, code structures, and unique model insights into a single master response.
- 📊 **Side-by-Side Model Comparison**: View response times, code implementations, and reasoning differences side-by-side in real-time.
- 🔐 **Privacy-First Client-Side Keys**: API keys are securely saved locally in your browser/device storage and never touch third-party servers.
- 💡 **High-Fidelity Simulation Mode**: Fully functional evaluation mode with zero setup required if no API keys are provided.
- 📱 **Native Android Integration**: Built with hardware acceleration, tactile haptics, clipboard integration, and native Android sharing bridge.

## 📱 Building & Installation

### Android APK (`PolyMind.apk`)

`PolyMind.apk` is compiled using Android SDK Build-Tools 34, D8 DEX compiler, 4-byte ZipAlignment, and `apksigner` with V1, V2, and V3 signatures for universal compatibility across Android 7.0 to Android 15+.

Download the latest APK from [GitHub Releases](https://github.com/apravint/polymind-ai/releases/tag/v1.0.0).
